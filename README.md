# Pocket Strike

スマホのブラウザで遊べるシンプルな FPS。`index.html` 1 ファイルだけで動く（three.js は CDN から読み込み）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホで遊ぶなら GitHub Pages などで公開して URL を開く。
ローカルで試すなら:

```sh
python3 -m http.server 8000
# 同じ Wi-Fi のスマホから http://<PCのIP>:8000 を開く
```

## 操作

| 入力 | スマホ | PC |
| --- | --- | --- |
| 移動 | 画面左側をドラッグ（仮想スティック） | WASD / 矢印キー |
| 視点 | 画面右側をドラッグ | マウス（クリックでポインタロック） |
| 射撃 | FIRE を長押しで連射（押したままドラッグで照準） | 左クリック |
| リロード | R ボタン（弾切れで自動） | R |
| 一時停止 | II ボタン | Esc / P |

## ルール

- ウェーブごとに敵が出てくる。全部倒すとアーマー +15 とボーナス点
- **SHOOTER**（紫）: 距離を取って弾を撃つ
- **RUSHER**（赤）: 突っ込んで自爆する
- **TANK**（黄）: WAVE 3 から出る。硬くて 3 連射
- 緑の十字を拾うとアーマー +25
- 遮蔽物で敵の弾を防げる。タッチ操作向けに少しだけエイムアシストあり

## 敵キャラを MMD モデルにする

開始画面の「敵モデルを読み込む (.zip)」から、MMD モデル（`.pmx` とテクスチャ一式）を入れた ZIP を選ぶと、敵がそのモデルに置き換わる。

- ZIP 内のファイル名でどの敵にするかを決める
  - SHOOTER: `莉奈娅` / `Linnea`
  - RUSHER: `结晶虫` / `bug`
  - TANK: `搭档` / `partner`
  - どれにも当てはまらない場合は一番大きい `.pmx` を全部の敵に使う
- 読み込んだ ZIP は端末のブラウザ内（IndexedDB）にだけ保存され、次回から自動で使われる。「外す」で削除
- スマホのメモリ対策でテクスチャは最大 1024px に縮小して使う
- 歩き・羽ばたきはコードで簡易的に動かしている（モーションファイルは不要）

モデルの利用規約で二次配布が禁止されていることが多いので、モデルファイルはこのリポジトリには入れない（`.gitignore` 済み）。
